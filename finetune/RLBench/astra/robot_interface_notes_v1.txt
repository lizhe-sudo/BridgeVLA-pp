Absolute position targets and measured EEF positions are in the RLBench world frame, in meters. The measured pose and target use the same Panda arm-tip reference (`Panda_tip`), which is also the IK tip in this setup; it is not a task-object pose or a pinch-point estimate.

Quaternions use XYZW order and describe the tip orientation relative to the world frame. The orientation matrix maps tool-local vectors into world coordinates; its columns are local +X, +Y, and +Z expressed in world coordinates. The robot base is placed by the loaded scene, so do not assume its axes align with world axes. Camera names identify sensors, not world directions.

For this Panda gripper geometry, local +Y spans the two fingers' opening direction, local +Z runs from the palm toward the finger ends, and local X is across finger thickness. Finger spacing changes with gripper opening; no fixed tip-to-fingertip or pinch-point offset is provided. Gripper command 0 closes and 1 opens. The arm target is planned first, then the discrete gripper command is applied. The measured `gripper_open` state is a boolean derived from the first normalized gripper-joint opening amount (>0.95 means open); it does not indicate that an object is held.
